INFORMACOES DEV - UNICIDFIT / BOSSFIT AI

1. RESUMO TECNICO
- Projeto front-end em HTML, CSS e JavaScript puro.
- Interface principal em index.html.
- Estilos em assets/css/styles.css.
- Logica do app em assets/js/app.js.
- Estrutura SQL do Supabase em supabase-schema.sql.

2. INTEGRACAO PREPARADA
- Supabase Auth para login e cadastro.
- Supabase Database para persistencia do quiz.
- Persistencia local com localStorage como fallback e draft temporario.
- Fluxo preparado para futuras expansoes com Storage e Edge Functions.

3. FLUXO DE DADOS
- Usuario autenticado entra no quiz.
- Responde perguntas em fluxo multi-step.
- JavaScript valida cada etapa.
- Respostas sao salvas localmente durante o preenchimento.
- Ao finalizar, o app monta um objeto com:
  objetivo
  nivel
  frequencia
  focoMuscular
  peso
  altura
- O sistema gera treino e plano semanal.
- Se o Supabase estiver configurado, ocorre persistencia no banco.

4. ESTRUTURA DO QUIZ
- Modal multi-step com 6 etapas:
  objetivo
  nivel
  frequencia
  foco muscular
  peso
  altura
- Navegacao com voltar e avancar.
- Barra de progresso visual.
- Validacao numerica:
  peso entre 20 e 400
  altura entre 80 e 250

5. CHAVES DE ARMAZENAMENTO LOCAL
- unicidfit_users
- unicidfit_session
- bossfit_ai_quiz_draft

6. CONFIGURACAO DO SUPABASE
- O app verifica:
  window.SUPABASE_URL
  window.SUPABASE_ANON_KEY
- Se nao houver credenciais validas, o projeto continua em modo local/demonstracao.
- Para ativar:
  definir SUPABASE_URL
  definir SUPABASE_ANON_KEY
  manter o script CDN do supabase-js no HTML
